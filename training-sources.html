Training Sources

Open and self-learning resources, one row per Skill Matrix component. Status is the same Covered/GAP read.

Component/SubsystemStatusResourceCostURLNotes
Airframe/structure (frame, arms, landing gear) Covered NPTEL — Design of Fixed-Wing UAV (IIT Kanpur) Free (cert: paid) https://onlinecourses.nptel.ac.in Structural/airframe design fundamentals, weight & CG estimation
Propulsion (motors, ESCs, props) Covered ArduPilot Dev Documentation Free https://ardupilot.org/dev/ Covers motor/ESC output config and calibration as part of vehicle setup
Power system (battery packs, BMS, charging) Covered Manufacturer BMS/battery safety training Varies (often free from cell/pack OEM) N/A — source from battery/BMS vendor No strong open-source course found; treat as vendor-training gap despite Medium-High complexity
Flight controller / autopilot (HW + firmware) Covered ArduPilot Developer Guide Free https://ardupilot.org/dev/ Learn-by-doing: build the code, work through the codebase, join weekly dev call
Flight controller / autopilot (HW + firmware) Covered PX4 Developer Guide (Dronecode/Linux Foundation) Free https://github.com/PX4/PX4-Autopilot Flight stack + middleware; SITL simulation via Docker, no hardware needed to start
Sensors (GPS, IMU, barometer, compass, LiDAR) Covered NPTEL — Drone Systems and Control Free (cert: paid) https://onlinecourses.nptel.ac.in Sensor calibration & Kalman filtering in MATLAB, autopilot design
RF/communication link & telemetry GAP Class Central — Drone Security course list Free (mostly conference talks/YouTube) https://www.classcentral.com/subject/drone-security Thin/unstructured — protocol hacking & RF vulnerability talks, not a formal curriculum. Confirms this as a real gap.
Payload (camera, gimbal, EO/IR) Covered OEM payload/gimbal calibration guides Varies by OEM N/A — source from camera/gimbal manufacturer No generic open course; calibration is payload-specific
Mission software / GCS (ground control station) GAP Open-Source Drone Programming Course (RoboticsAcademy) Free https://jderobot.github.io/RoboticsAcademy/ Practical aerial robotics exercises: road-following, visual landing, search-and-rescue; 5+ years in university use
Cybersecurity (anti-jam, anti-spoof, data integrity) GAP Class Central — Drone Security course list Free (mostly conference talks/YouTube) https://www.classcentral.com/subject/drone-security Same source as RF/comms — covers GPS-spoofing and hardware compromise talks, not certification-grade training
Autonomy/AI (obstacle avoidance, swarm logic) GAP Open-Source Drone Programming Course (RoboticsAcademy) Free https://jderobot.github.io/RoboticsAcademy/ Covers autonomous navigation exercises usable as an AI/autonomy starting point
Quality/airworthiness sign-off Covered DGCA / Digital Sky official guidance Free (RTO training itself is paid) https://digitalsky.dgca.gov.in Regulatory basis for Type Certificate, RPC, and compliance documentation
Test flight & acceptance Covered DGCA-approved RPTO training (for RPC) Paid (₹25,000–1,50,000 per published fee surveys) N/A — choose a DGCA-approved RPTO No open/free path — RPC is a mandatory paid certification, not self-taught
Parts genealogy/traceability data Covered N/A — internal capability N/A N/A Already covered by your existing PySpark/Databricks/SCN background; no external course needed
